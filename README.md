# Matsu RallyCon v0.8.5 UNIVERSAL PDF

v0.8.4ベースのPDF表示位置復元改善版。

## v0.8.5 change
- PDF表示モードのNEXT/BACKでページ境界をまたぐ際、離れるページのスクロール位置を保存。
- 次ページからBACKして前ページへ戻ったとき、前ページの先頭へ戻らず、直前にいたスクロール位置（通常は下側）へ復元。
- 各表示単位ごとにスクロール位置を保持。次ページ側をスクロールしてから戻る場合も、ページ内スクロール→境界移動の操作感を維持。
- 自由スワイプ後にページをまたいだ場合も、最後の位置を復元。
- PDF読み込み3モード、A4横2面表示、A5/A4コマ練解析、GPS、TOTAL/LEG、AUTO NEXT、PDF送り量30.0～200.0%・0.1%刻み、長押し加速、時刻中央表示など既存機能は維持。

## Intended behavior
- NEXT: 設定倍率で下方向へスクロール。下端でさらにNEXTすると次の表示単位へ。
- BACK: 設定倍率で上方向へスクロール。上端でさらにBACKすると前の表示単位へ。
- ページ境界を越えた後に逆方向へ戻ると、直前に離れたページの保存位置へ復元する。
- PAGE ‹ / PAGE › は表示単位を直接移動する操作として維持。
