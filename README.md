# Matsu RallyCon v0.8.33
UNIVERSAL PDF + A5 RALLY VIEW / 電動マップホルダー風連続スクロール試作

## 変更点
- v0.8.24の縦RALLY VIEW、PDF表示モード縦RALLY VIEW、送り補正を維持。
- 横画面の連続スクロールでBACKが前ページへ移動した際、前ページの先頭へジャンプせず、前ページ下端から再開するよう修正。
- START後のPDF表示モード（LONGPDF / PDFVIEW）で、NEXT/BACKを長押しすると電動マップホルダー風の連続スクロールを開始。
- 長押ししている間だけ連続してスライドし、離すとその位置で停止。
- ゆっくり動き始めて短時間で速度が上がる、緩やかな加速式。
- 短押しは従来どおり1回送り。
- 縦RALLY VIEWでは連結されたPDF全体を連続スクロール。
- 横画面では従来のPDF表示領域を連続スクロールし、表示単位境界では既存のページ移動処理を利用。
- START前のNEXT/BACK長押しによる「PDFコマ送り量」設定は従来どおり。
- A5コマ練モードのNEXT/BACK長押しは今回変更せず、従来の1コマ送りを維持。
- v0.8.24の縦ヘッダー表示、GPS、既存PDF表示、PDFタップ/ピンチ/ダブルタップ等を維持。

## v0.8.29の修正
- NEXTで次ページへ移動するときは次ページ上端から継続。
- BACKで前ページへ移動するときは前ページ下端から継続。
- これにより横画面でも巻き取り方向に対してページ境界のジャンプ感を抑制。
- v0.8.27で確認済みの巻き取り速度（55～160px/s）は変更なし。

## 連続スクロール試作の操作
### 走行前
NEXT/BACK長押し（約0.7秒） -> 「PDFコマ送り量」設定

### START後 / PDF表示モード
短押し -> 従来どおり1回送り
長押し -> 電動マップホルダー風に連続スクロール
離す -> その位置で停止

## 対象
- LONGPDF
- PDFVIEW
- PDF表示モードの縦RALLY VIEW / 横画面

A5コマ練の連続スクロールは今回まだ対象外。既存のA5コマ練動作を優先して保持している。

## v0.8.30 GPS LOST復帰表示の即時化
- v0.8.29をベースに、GPS LOST→有効なGPS復帰時の表示経路だけを変更。
- 復帰GPSで補正距離を計算した直後に、GPSステータスとTOTAL/LEG等を即時更新。
- 復帰時の表示更新ではlocalStorageへのセッション保存を待たず、ブラウザの描画を優先。
- セッション保存は表示更新後の次のタスクへ延期し、復帰表示までの同期処理を短縮。
- GPS距離の推定方法、GPS LOST判定、復帰補正の計算式、速度推定による補完は変更なし。
- 二重加算防止のため、復帰補正後に現在位置を新しいGPS基準点として更新。
- A5コマ練、PDF表示、RALLY VIEW、NEXT/BACK、電動マップホルダー風連続スクロール等は変更なし。

### v0.8.30 検証

- 実機走行でのGPS LOST→復帰表示時間は未確認。v0.8.30はこの点を実走テストするための版。


## v0.8.31 横画面PDF連続スクロールの停止時ジャンプ修正
- v0.8.30をベースに、横画面PDF読み込みモードのNEXT/BACK長押し終了時だけを修正。
- 長押し中に電動マップホルダー風連続スクロールが開始された場合、ボタンを離した直後のブラウザ合成clickを通常のNEXT/BACKとして処理しないよう修正。
- これにより、ボタンを離した瞬間にPDFコマ送り率の通常送りが追加発動して、一気にページ/表示位置がジャンプする現象を防止。
- 長押し中の連続スクロール自体、停止位置、スクロール速度、ページ境界処理は変更なし。
- 短押しは従来どおり1回送り。
- START前の長押しによる「PDFコマ送り量」設定も変更なし。
- 縦RALLY VIEW、A5コマ練、GPS、その他の既存機能は変更なし。

### v0.8.31 検証
- v0.8.30から対象イベント処理の差分を確認。
- 長押し開始後はpointerup時に抑制フラグを解除せず、後続onclickがフラグを消費して終了することを確認。
- 短押しでは抑制フラグが立たず、既存の1回送り処理が実行されることを確認。
- インラインJavaScriptの構文チェックを実施。
- 実機での横画面PDF長押し停止時ジャンプは、v0.8.31での走行/操作テストが必要。
