# Matsu RallyCon v0.8.6 UNIVERSAL PDF

v0.8.5をベースに、PDFコマ送り量の直接入力機能を追加した版。

- PDF読み込みモード：自動判定 / コマ練 / PDF表示
- PDF表示：NEXT/BACKの設定％スクロール、端で次/前表示単位へ移動
- ページ境界をまたいだBACKで直前位置を復元
- PDFコマ送り量：30.0～200.0%、0.1%刻み
- ＋/−短押し：±0.1%
- ＋/−長押し：保持時間に応じて段階的に高速化
- **PDFコマ送り量の％数字を長押し：任意の数値を直接入力可能**
- 直接入力値は30.0～200.0%に制限し、0.1%単位に正規化
- スワイプ：PDFを任意位置へ自由移動
- A5/A4/GPS等の既存機能を維持
