# Matsu RallyCon v0.8.14

UNIVERSAL PDF + 縦画面RALLY VIEW / A5連続スクロール

## v0.8.14変更点
- iPhone等の縦画面で、A5コマ練PDFを走行用の「RALLY VIEW」として連続表示。
- A5のコマ図ページを縦方向につなげ、紙のロードブックのように上下へ連続スクロール可能。
- 走行中は上部にTOTAL kmとSPEED km/hだけをオーバーレイ表示し、コマ図表示領域を最大化。
- 走行開始前は既存の操作UIを残し、START後に走行用の最小表示へ切り替える。
- GPSによるAUTO NEXT等でRBが進んだ場合は、該当コマ付近へ連続表示を追従。
- 横画面は従来のv0.8.13表示を維持。
- A5以外のPDF表示は従来動作を維持。

## 操作
- 縦画面・A5：コマ図を上下スワイプして自由に連続スクロール。
- 走行中：TOTAL / SPEEDを常時確認可能。
- 既存のGPS、TOTAL/LEG、AUTO NEXT、PDF読み込み、A4/A5解析等は維持。

## 注意
- 本版の新機能はA5コマ練PDFの縦画面表示を対象とする。
- iPhone実機での縦画面連続スクロールは、配布後に実機確認が必要。
- v0.8.13のGPS LOST→復帰時の直線距離補正もそのまま維持。
