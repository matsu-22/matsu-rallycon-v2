# Matsu RallyCon v0.7.6 UNIVERSAL PDF

v0.7.5 UNIVERSAL PDFをベースに、特殊PDF表示時のコマ送り操作を追加。

## 特殊PDFのコマ送り
対象：LONGPDF / PDFVIEW
- NEXT：次の位置へ送る
- BACK：前の位置へ戻す
- 画面を上へスワイプ：次へ
- 画面を下へスワイプ：前へ
- 送り量＝現在のPDF表示エリア高さ × 設定倍率
- 初期値100%
- 30～200%
- NEXT長押し：約0.7秒で「PDFコマ送り量」設定を開く
- 設定は±10%、長押しで連続変更
- ズームが1倍より大きい場合は従来の自由パンを維持

## 通常のA4/A5
通常のA5コマ練形式は距離・RB等を従来どおり自動解析。
A4も従来処理を維持。
BACK / NEXTは通常どおりRB移動。

## GPS
- GPS ON/OFF
- GPS距離計測
- GPS距離補正50～150%、1%刻み
- GPS補正ボタン長押しによる連続変更
- TOTAL / LEG / TIME
- GPS LOST / 復帰
- セッション保存・復元
- START長押しリセット

## 汎用PDF
A4/A5として判定できないPDFは距離・RB番号を自動解析せず、PDFそのものを表示。
その場合はPDFを見ながらGPSラリコンとコマ送りを併用。
