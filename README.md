# Matsu RallyCon v0.8.4 UNIVERSAL PDF

v0.8.2のPDF読み込みモード選択に加え、A4横向きの「1ページ内2面」PDFを表示専用で個別表示できるようにした版です。

- 自動判定: 対応A5/既知A4のみ距離・RB解析。未知形式はPDF表示
- コマ練モード: 対応形式として解析。非対応形式は読み込み中止
- PDF表示モード: 距離・RBを一切解析せず、NEXT/BACK固定送り＋スワイプ自由移動
- 2面PDF: 左右を個別の表示単位として扱い、NEXT/BACK・PAGEで面送り
- 1面目の片側が注意書き等で、反対側からロードブックが始まる形式も判定
- 特殊PDFの送り量: 30.0～200.0%、0.1%刻み、長押しで段階的に加速
- 時刻のみ中央表示
- A4/A5解析、GPS機能、既存セッション機能を維持

本番前に、使用するPDFで選択モード、表示面、NEXT/BACK、PAGE、スワイプの動作を確認してください。


## v0.8.4 change
PDF表示モードのNEXT/BACKは、まず設定した送り量でスクロールし、ページ（表示単位）の端に到達して追加スクロールできない場合は自動的に次/前の表示単位へ移動します。PAGE ‹/›も表示単位移動として維持します。A4 2面PDFは左右を1表示単位として扱います。
