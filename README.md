## v0.8.35 起動時の標準コマ図をA5版なのはなラリーへ変更

- 起動時のA5 PDFは既存のA5コマ練自動解析を通し、11ページ・66RBのロードブックとして読み込む構成。
- 表紙ページ（PDF 1ページ）は解析対象外で、ロードブック1ページ目（PDF 2ページ）から開始する既存A5マッピングを維持。
- TOTAL / INTER / RB、NEXT/BACKなどのA5コマ練機能は既存処理を使用し、新しいPDF専用の距離データをハードコードしない。
- LOAD PDFでユーザーが別PDFを読み込む通常機能には変更なし。
- v0.8.34で実機確認済みの縦PDFレイアウト、横画面、ウィーン連続スクロール、GPS等の処理は変更しない。

## 連続スクロール試作の操作

NEXT/BACK長押し（約0.7秒） -> 「PDFコマ送り量」設定
