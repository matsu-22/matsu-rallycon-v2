# Matsu RallyCon v0.8.14

## A5縦画面RALLY VIEW 再構築版

v0.8.14は、v0.8.13 GPS版を直接の基準にして、A5縦画面の連続表示を独立表示レイヤーとして追加した再構築版です。v0.8.14〜v0.8.16で発生したコマ位置ズレ・NEXT/BACK干渉・START後ブラックアウトを避けるため、既存のPDF/RB移動ロジックを置き換えず、縦画面時だけ連続表示を利用します。

### 縦画面A5
- A5コマ練モード：コマ図ページを縦方向につなげて連続表示
- コマ練NEXT/BACK：既存のRB移動を使用し、移動先のコマ位置へ連続表示を追従
- PAGE ‹ / PAGE ›：既存の論理ページ移動を使用
- 自由な上下スワイプ：連続表示を通常の縦スクロールとして使用
- START/STOP：連続表示を消さず、走行時はTOTAL/SPEEDを上部に表示
- PDF表示モード：A5サイズとして判定されたPDFも連続表示
- PDF表示モードは距離/RB解析を行わず、既存のPDF表示操作を維持

### 横画面
横画面では連続表示を使用せず、v0.8.13の既存PDF/RB表示をそのまま使用します。

### GPS
v0.8.13のGPS LOST→復帰時の直線距離補正をそのまま維持しています。GPS計算ロジック自体は今回変更していません。

### その他
TOTAL / LEG / AUTO NEXT / GPS補正 / A4 / A5解析 / 未知PDF表示 / PDFズーム・パン / PDF送り量設定 / セッション保存 / START長押しリセット等の既存機能を維持します。
