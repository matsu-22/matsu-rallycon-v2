# Matsu RallyCon v0.8.23
UNIVERSAL PDF + A5 RALLY VIEW

## 変更点
- v0.8.22で確認したPDF表示モードの縦RALLY VIEWを維持。
- v0.8.20で確認済みの縦RALLY VIEWの自由スクロール、START、NEXT/BACKを維持。
- v0.8.22で採用した「A5コマ図の行間隔を基準に、20.0%を約1コマとする」送り量計算を維持。
- 縦RALLY VIEWのPDF表示モードだけに「縦RALLY VIEW 送り補正」を追加。
- 既存のPDFコマ送り量の表示・設定範囲は従来どおり20.0～200.0%、0.1%刻み。
- 縦RALLY VIEW送り補正は80.0～110.0%、0.1%刻み、初期値100.0%。
- 実際の縦送り量は、従来の縦送り量 ×（縦RALLY VIEW送り補正 / 100）で算出。
- これにより、画面上のPDFコマ送り量を20.0%のまま、実際の送り幅だけを100%未満へ微調整可能。
- 補正値の±ボタンは0.1%刻み。長押しで既存の加速ステップを使った連続調整が可能。
- 補正値は縦RALLY VIEWのPDF表示モード専用で、A5コマ練・横画面・通常PDF表示の既存送り量には影響しない。

## 操作
PDF表示モードでNEXTボタンを約0.7秒長押しして「PDFコマ送り量」設定を開く。
その中の「縦RALLY VIEW 送り補正」で微調整する。

例：PDFコマ送り量20.0%の場合
- 補正100.0% → v0.8.22と同じ送り幅
- 補正98.0% → v0.8.22の98%の送り幅
- 補正95.0% → v0.8.22の95%の送り幅
- 補正105.0% → v0.8.22の105%の送り幅
