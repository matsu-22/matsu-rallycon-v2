# Matsu RallyCon v0.6 FRESH

GitHub Pagesへ新規投入する前提のクリーン版です。

## 今回の表示改善
- A4 PDFの物理ページをそのまま縮小せず、コマ図の論理ページ（1コマ図ページ）だけを中央に表示
- `コマ図 1 / 39` のように論理ページ単位で移動
- 上下ドラッグで縦スクロール
- 2本指ピンチ、ダブルタップ、＋/−で拡大縮小
- 右側のROADBOOKとTOTAL距離に連動して論理ページを自動切替
- LOAD PDFで別PDFも表示可能

## デモPDF
`demo/KOMAREN_Classic2026.pdf` は今回のコマ練Classic2026 PDF。

## 注意
自動同期のルート番号はこのデモPDF用です。別イベントPDFではPDF表示はできますが、自動同期用のルートデータは別途設定が必要です。
